## 📌 Overview

This project showcases semantic HTML structure, accessibility principles, and form controls across two core web pages.

---

## 📂 Project Files

Click on either file below to view the source code:

1. [Profile Page (`index.html`)](./index.html)  
   - Semantic page layout structured with rich textual organization utilizing description lists (`<dl>`, `<dt>`, `<dd>`), unordered lists (`<ul>`, `<li>`), and semantic emphasis tags like `<strong>`.

2. [Sign In (`form.html`)](./form.html)  
   - Structured form controls including text fields, email, passwords, etc.
   - Form accessibility built with explicit `<label>` bindings and client-side input validation.
